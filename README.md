
# College Management System in C

A menu-driven College Management System developed using C programming.

## Features

1. Student Attendance Management
2. Timetable Management
3. Canteen Menu Management
4. College Events Management

## Concepts Used

- Structures
- Arrays
- Functions
- Loops
- Switch Case
- File Handling

## Technologies

- C Programming
- GCC Compiler
- Visual Studio Code

## How to Run

Compile the program:

```bash
gcc main.c -o college
```

Run the program:

```bash
./college
```
